House Price Prediction System

This project was developed as a machine learning application that predicts house prices using the California Housing dataset.

The system demonstrates the use of regression techniques, data preprocessing, visualization, and predictive analytics using Python.

The project combines frontend web development and machine learning to create an interactive prediction platform for users.
